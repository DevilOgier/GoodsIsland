# 收支账本

入口：侧边栏「收支账本」，手机在「我的 → 收支账本」。支持月份、IP、角色、系列、谷子类型和流水状态筛选，支持导出当前流水 CSV。

- 月份仅影响收入、支出、净收支和流水。收支按登记的购入日期 / 成交日期计入；晚补费用按追加记录创建当天（北京时间）计入，避免重复加入原购入月份。
- 取消购买排除。挂出和心愿不会成为收入或支出。
- 当前在手成本是库存实际成本；尚未到手是待到货 / 运输中购买的实际成本（含补费）。
- 累计已入库金额表示所有到货购买的成本，包含后来已卖出的部分；当前在手成本只表示剩余库存。
- 累计已售利润 = 成交收入 - 原成交分摊成本 - 后补成本调整。
- 角色、系列和类型筛选同时影响累计与月度统计。累计数据不会随月份和流水状态变动，页面有明确说明。
- 金额在统计层使用整数分 BigInt，避免浮点累计误差。

这是根据谷子交易记录生成的账本；没有独立付款 / 退款日期或银行对账数据，不代表银行实际现金流水。当前不包含其他生活开支的手工记账或市场估值。

图片维护集中在「图鉴管理」。商品详情、买入和库存浏览不提供上传、增强或切换图片按钮。图片写接口仍要求管理员身份，不以页面来源代替鉴权。
