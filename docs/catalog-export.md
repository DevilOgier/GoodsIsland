# 类型图鉴长图

## 使用
图鉴 → 导出类型图鉴 → 类型 / 角色 / 标题 → 获取长图。
有远端缓存时直接下载 PNG；缺少缓存时加入持久化队列，后台生成，关闭窗口不会丢失任务。
默认单张长图，1440 px 宽，按数量增加高度，最多 500 款（避免超大图片造成服务端内存压力）。超过时提示缩小筛选，不自动分张。
仅包含共享图鉴数据，不包含库存、买卖记录或个人金额；接口仍要求登录。

## 后台与存储
生产 compose 的 worker 通过 scripts/workers.mjs 同时管理现有增强 worker 与独立的 catalog worker；任一退出会触发容器重启。
首次启动以及北京时间每天 03:00 后，预登记所有非空类型及类型+角色的默认图鉴。
已有自定义请求也在次日更新。未改变的数据根据 fingerprint 复用 PNG。
新请求默认每 5 秒取一次；单个任务失败 15 分钟后重试，已有成品不会被失败任务覆盖。
无数据库迁移。请求和结果文件保存在 CATALOG_EXPORT_DIR，生产为 image-data 持久卷中的 /app/data/objects/catalog-jobs。
图片通过现有 putObject/readObject 存在 catalog/<hash>，兼容文件存储或 S3。
多容器必须共享 CATALOG_EXPORT_DIR（S3 只保存成品，任务目录仍需共享卷）。
按日批次不是精确实时刷新；03:00 开始检查，完成时间取决于图鉴规模。

## 本地运行
启动本地服务和网页后，另行执行 pnpm worker:catalog。
服务端用现有 OFL 文楷的无损 TTF 转换版本，存于 assets/fonts，不传给浏览器。
浏览器只负责轻量预览及下载，服务器 sharp 渲染 SVG → PNG。
