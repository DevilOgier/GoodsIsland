# 图片浏览与海报交互更新

- 小岛四项统计进入对应图片卡片页，右上角可切换列表；等待到货包含未发货和已发货记录。
- 图鉴管理支持新增/编辑时上传图片，也可在管理行直接上传。谷子类型支持自定义；新建和编辑时由服务端生成「角色名 · 系列 · 类型」，已有商品在编辑保存时更新名称。
- 购入选择器先展示系列拼图，可按 IP、角色和文字筛选，进入系列后选择具体类型。出售选择限定在手商品。
- 小岛提供制作收物图和出物图入口；记录卡片也可单独制作。自动填入未完成数量、价格、备注和选用图片，不改变库存或挂单。
- 海报模板 v2 分为奶油手帐（拍立得）、清新画廊（主图）、复古票根（票券）、极简留白（编号图文）。保留 v1 渲染和数据库版本，使已保存旧海报继续可编辑。

## 数据迁移与运行

运行 start-local.ps1 会自动应用新增 ProductType 表和海报 v2 的迁移；数据库、图片与连接配置沿用现有 .env。

## 验证

- 类型检查、ESLint、生产构建。
- 单元测试：成本计算、四种模板结构、旧模板兼容、收出物预填。
- 数据库集成测试：自动命名、自定义类型、非法类型、库存成本与补运费。
- scripts/visual-flow-check.mjs：四个统计入口、图片/列表、上传、自定义类型、系列拼图选购、收出物预填与导出、库存不变、六种视口。
- scripts/browser-check.mjs：原有交易、图片、海报与 PWA 回归。

浏览器测试创建并清理独立测试用户与商品，不重置实际用户数据库。
