# Invitation Song

Derived from Noto Serif SC variable font, weight 600, packaged as WOFF2.
Source project: https://github.com/notofonts/noto-cjk
License: SIL Open Font License 1.1; see OFL-NotoSerifSC.txt.
Official license source: https://github.com/google/fonts/blob/main/ofl/notoserifsc/OFL.txt

Built with fontTools varLib.instancer (wght=600) and subset:
U+0000-00FF, U+2000-206F, U+3000-30FF, U+3400-9FFF, U+FF00-FFEF.
This preserves CJK unified ideographs, kana, common punctuation and Latin.
The runtime family is Goods Island Song. Only Invitation requests this asset.
